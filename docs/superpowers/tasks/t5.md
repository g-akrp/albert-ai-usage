# Task t5: Retain last-known report on transient error + per-card retry

## Goal
Preserve the last-known good `Report` (with an orange `"Stale: <error>"` notice) when a provider fails transiently, instead of wiping percentages from the panel and MCP snapshot, and add a per-card hover retry button (`arrow.clockwise`) so a single provider can be retried without rerunning all providers.

## Required Interfaces & Behavior
1. In `Sources/AIUsageCore/PixelIcon.swift` (`struct ProviderRun`):
   - Add `public var staleError: String?` (default `nil` in both `init` overloads so existing call sites compile unchanged).
   - Add static helper:
     ```swift
     public static func merging(previous: [ProviderRun], latest: [ProviderRun]) -> [ProviderRun]
     ```
     - Multi-account listing failure case: if `latest.count == 1`, `case .failure(let err)? = latest[0].result`, `latest[0].id == latest[0].configId`, and `previous` contains at least one `.success` run with `configId == latest[0].configId`: return those previous `.success` runs with `staleError = err.message` (preserving their `id`, `name`, `iconLabel`, `iconColor`, `result`, `configId`, `providerName`, `account`).
     - Otherwise, for each run in `latest`:
       - If `case .failure(let err)? = run.result` and matching `previous` run (same `id`) has `case .success(let report)? = prev.result`: emit a `ProviderRun` keeping `prev`'s `.success(report)` (and `prev.iconLabel`, `prev.name`) with `staleError = err.message`.
       - If `case .success? = run.result`: emit `run` with `staleError = nil`.
       - Otherwise (`.failure` with no prior `.success`, or `nil`): emit `run` with `staleError = nil`.
2. In `Sources/AIUsageCore/CardModel.swift`:
   - Add `public let configId: String` to `Card`, with `configId: String? = nil` (defaulting to `id`) in `Card.init` so existing tests stay untouched.
   - In `CardModel.card(...)`: set `configId: run.configId`; on `.success(let report)?`, if `let err = run.staleError`, append `CardNotice(text: "Stale: \(err)", tone: .orange)` to `notices`.

   - In `UsageSnapshot.provider(from:)`: on `.success(let report)?`, set `message: run.staleError.map { "Stale: \($0)" }` (keeps `status: "ok"` and valid `remainingPercent` + `windows`).
4. In `Sources/AIUsage/Poller.swift`:
   - In `finish(_:_:)` (around lines 125-137):
     - IMPORTANT: compute `let failed = results.allSatisfy { ... }` on raw `results` BEFORE merging so exponential backoff (`state.failures`) still increments on transient failures!

   - Add `func refresh(configId: String)`:
