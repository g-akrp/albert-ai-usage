# Task t3: Window pacing / elapsed tick on concentric rings

## Goal
Compute each window's elapsed fraction from `resetsAt` and `durationSeconds`, expose it on `CardRing`, and draw a radial elapsed-time tick mark on each ring in `CardView` so users can immediately see whether usage is ahead of or behind pace.

## Allowed files to edit
- `Sources/AIUsageCore/Report.swift`
- `Sources/AIUsageCore/CardModel.swift`
- `Sources/AIUsage/CardView.swift`
- `Sources/CoreChecks/ModelChecks.swift`

## Required Interfaces & Behavior
1. In `Sources/AIUsageCore/Report.swift` (`struct WindowReport`):
   - Add:
     ```swift
     public static func elapsedFraction(resetsAt: Date?, durationSeconds: Int?, at now: Date) -> Double?
     public func elapsedFraction(at now: Date) -> Double?
     ```
   - Requires `let resetsAt`, `let duration = durationSeconds`, `duration > 0` (returns `nil` otherwise, e.g. Copilot windows without `durationSeconds`).
   - Returns `min(max(1 - resetsAt.timeIntervalSince(now) / Double(duration), 0), 1)`.
2. In `Sources/AIUsageCore/CardModel.swift`:
   - Add `public let elapsed: Double?` to `CardRing` with initializer:
     ```swift
     public init(fraction: Double?, tone: Tone, elapsed: Double? = nil)
     ```
     (Default `nil` keeps existing call sites and tests compiling.)
   - Update `CardModel.Env.ring` to pass `elapsed`:
     - In `windowChart`: `window.elapsedFraction(at: now)`.
     - In `mergedChart`: `meter.windows.first?.elapsedFraction(at: now)`.
3. In `Sources/AIUsage/CardView.swift` (`drawChart`, around lines 428-466):
   - For each ring where `let elapsed = chart.rings[index].elapsed`, `elapsed > 0`, `elapsed < 1`:
     - Draw a crisp radial tick mark across the ring from `radius - Self.thickness / 2 - 1` to `radius + Self.thickness / 2 + 1` at clockwise angle `-Double.pi / 2 + 2 * Double.pi * elapsed`.
     - Use `lineWidth = 1.5`, `lineCapStyle = .round`, color `NSColor.labelColor.withAlphaComponent(0.75)`.
     - Draw AFTER the ring's filled usage arc so the tick remains clearly visible whether usage is ahead of or behind elapsed time.
