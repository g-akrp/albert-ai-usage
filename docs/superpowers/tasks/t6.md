# Task t6: `--json` CLI flag, richer `UsageSnapshot` fields, and `README.md`

## Goal
Expose `durationSeconds`, live `elapsedPercent`, and `count` (used/limit/unit) in `UsageSnapshot` / MCP `usage` output, add an `AIUsage --json` CLI flag that prints the snapshot JSON and exits without launching AppKit, and update `README.md` to document all six enhancements.

## Allowed files to edit
- `Sources/AIUsageCore/SnapshotFile.swift`
- `Sources/AIUsageCore/McpServer.swift`
- `Sources/AIUsageCore/UsageSnapshot.swift`
- `Sources/AIUsage/main.swift`
- `Sources/CoreChecks/UsageChecks.swift`
- `README.md`

## Required Interfaces & Behavior
1. In `Sources/AIUsageCore/SnapshotFile.swift`:
   - Add:
     ```swift
     public static let missingMessage = "AIUsage app is not running or has no snapshot yet"
     public static func isNotFound(_ error: Error) -> Bool
     ```
     Matches `NSCocoaErrorDomain` + `NSFileReadNoSuchFileError` or `NSPOSIXErrorDomain` + `Int(ENOENT)`.
2. In `Sources/AIUsageCore/McpServer.swift`:
   - Replace private `isNotFound` and inline string with `SnapshotFile.isNotFound(error)` and `SnapshotFile.missingMessage`.
3. In `Sources/AIUsageCore/UsageSnapshot.swift`:
   - Add:
     ```swift
     public struct UsageCount: Codable, Equatable {
         public let used: Double
         public let limit: Double
         public let unit: String?

         public init(used: Double, limit: Double, unit: String? = nil) {
             (self.used, self.limit, self.unit) = (used, limit, unit)
         }
     }
     ```
   - Extend `UsageWindow`:
     ```swift
     public struct UsageWindow: Codable, Equatable {
         public let id: String
         public let label: String?
         public let remainingPercent: Double?
         public let resetsAt: Date?
         public let durationSeconds: Int?
         public let count: UsageCount?

         public init(id: String, label: String? = nil, remainingPercent: Double? = nil, resetsAt: Date? = nil,
                     durationSeconds: Int? = nil, count: UsageCount? = nil)
     }
     ```
   - In `UsageSnapshot.provider(from:)`: populate `durationSeconds: w.durationSeconds` and `count: w.count.map { UsageCount(used: $0.used, limit: $0.limit, unit: $0.unit) }`.
   - In `UsageSnapshot.view(now:)`: on each window dict, add:
     - `"durationSeconds": duration` when `w.durationSeconds` is non-nil.
     - `"elapsedPercent": (fraction * 1000).rounded() / 10` when `WindowReport.elapsedFraction(resetsAt: w.resetsAt, durationSeconds: w.durationSeconds, at: now)` is non-nil.
     - `"count"`: `["used": c.used, "limit": c.limit]` (+ `"unit": unit` if non-nil) when `w.count` is non-nil.
   - Add:
     ```swift
     public static func cliJSON(load: () throws -> Data, now: Date = Date()) -> (output: String, exitCode: Int32)
     ```
     - Loads and decodes snapshot, encodes `snapshot.view(now: now)` with `JSONSerialization.data(withJSONObject:options: [.sortedKeys, .withoutEscapingSlashes])` -> returns `(jsonString, 0)`.
     - On load error: uses `SnapshotFile.missingMessage` when `SnapshotFile.isNotFound(error)`, else `error.localizedDescription`; returns compact JSON `{"error":"..."}` and `exitCode: 1`.
     - On decode/encode error: returns compact JSON `{"error":"..."}` and `exitCode: 1`.
4. In `Sources/AIUsage/main.swift`:
   - Before `NSApplication.shared` (next to the `--mcp` branch):
     ```swift
     if CommandLine.arguments.contains("--json") {
         let result = UsageSnapshot.cliJSON(load: { try Data(contentsOf: SnapshotFile.url) }, now: Date())
         print(result.output)
         fflush(stdout)
         exit(result.exitCode)
     }
     ```
5. In `README.md`:
   - Update concisely to document:
     - `--json` CLI flag (prints snapshot JSON, exits 0 on ok / 1 on error).
     - New `windows` fields (`durationSeconds`, `elapsedPercent`, `count`) in MCP / `--json` payload.
     - **Most Urgent** menu bar mode (alongside Pin and Cycle Menu Bar, and Cycle showing only non-hidden cards).
     - Window pacing tick on rings (when duration is known).
     - Automatic refresh when a window's `resetsAt` passes.
     - Last-known usage retained with a `Stale:` notice on transient errors + per-card hover retry button.
