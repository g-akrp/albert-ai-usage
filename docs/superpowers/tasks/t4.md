# Task t4: "Most Urgent" menu bar mode

## Goal
Add a "Most Urgent" menu bar mode alongside fixed Pin and 3-second Cycle Menu Bar, so the menu bar icon automatically displays whichever shown provider (or grouped model group) has the highest used percent, with legacy `cycleIcon` UserDefaults migration.

## Allowed files to edit
- `Sources/AIUsageCore/PixelIcon.swift`
- `Sources/AIUsageCore/MenuModel.swift`
- `Sources/AIUsageCore/PanelModel.swift`
- `Sources/AIUsage/StatusController.swift`
- `Sources/CoreChecks/ModelChecks.swift`
- `Sources/CoreChecks/PanelChecks.swift`

## Required Interfaces & Behavior
1. In `Sources/AIUsageCore/PixelIcon.swift`:
   - Add:
     ```swift
     public enum MenuBarMode: String, Equatable {
         case pinned, cycle, urgent

         public static func resolve(stored: String?, legacyCycle: Bool) -> MenuBarMode {
             if let stored, let mode = MenuBarMode(rawValue: stored) { return mode }
             return legacyCycle ? .cycle : .pinned
         }
     }
     ```
   - In `enum Pin`, add:
     ```swift
     public static func mostUrgent(in runs: [ProviderRun], order: [String], hidden: Set<String>) -> String?
     ```
     - Filters candidates via `Pin.cycleCandidates(runs, order: order, hidden: hidden)`.
     - If empty, returns `nil`.
     - Among candidates with `.success(let report)` and non-nil `report.maxPercent`, picks the one with the highest `maxPercent` (ties broken by candidate/card order).
       - If `CardModel.isGrouped(report)`, picks the meter in `report.meters` with the highest `maxPercent` (ties broken by meter order) and returns `Pin.key(run: run.id, meter: worstMeter.id)`.
       - Otherwise returns `CardModel.titlePin(run)`.
     - If no candidate has a numeric `maxPercent`, prefers the first candidate with `.failure` (`CardModel.titlePin(run)`), else `CardModel.titlePin(candidates[0])`.
2. In `Sources/AIUsageCore/MenuModel.swift`:
   - Add `case mostUrgent(Bool)` to `MenuEntry`.
   - Extend `MenuModel.entries(...)` with defaulted parameter `mostUrgent: Bool = false` (right after `cycling: Bool = false`).
   - Emit `.mostUrgent(mostUrgent)` right after `.cycleIcon(cycling)`.
3. In `Sources/AIUsageCore/PanelModel.swift`:
   - Add `mostUrgent` to `PanelRow.Kind`.
   - In `PanelModel.rows(...)`, map `.mostUrgent(let on)` to `PanelRow(.mostUrgent, "Most Urgent", checked: on)`.
4. In `Sources/AIUsage/StatusController.swift`:
   - Replace `cycling: Bool` storage with `menuBarMode: MenuBarMode`:
     - Getter: `MenuBarMode.resolve(stored: defaults.string(forKey: "menuBarMode"), legacyCycle: defaults.bool(forKey: "cycleIcon"))`
     - Setter: `defaults.set(newValue.rawValue, forKey: "menuBarMode")`
   - Keep `private var cycling: Bool { menuBarMode == .cycle }` (or inline `menuBarMode == .cycle`) so `updateCycleTimer()` still runs only when `menuBarMode == .cycle`.
   - In `updateIcons()`:
     - `.pinned`: `effective`
     - `.cycle`: `Pin.cycle(cycleStep, in: cycleRuns) ?? effective`
     - `.urgent`: `Pin.mostUrgent(in: visibleRuns, order: cardOrder, hidden: hiddenCards) ?? effective`
   - In panel `pin` closure: set `menuBarMode = .pinned` and call `updateCycleTimer()` before `updateIcons()`.
   - In `content()`: pass `cycling: menuBarMode == .cycle, mostUrgent: menuBarMode == .urgent` to `MenuModel.entries(...)`.
   - In `rowClicked`:
     - `.cycleIcon`: `menuBarMode = menuBarMode == .cycle ? .pinned : .cycle`; `updateCycleTimer()`; `updateIcons()`.
     - `.mostUrgent`: `menuBarMode = menuBarMode == .urgent ? .pinned : .urgent`; `updateCycleTimer()`; `updateIcons()`.
